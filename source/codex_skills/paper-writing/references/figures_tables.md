# Figures and Tables

## Table Types

- Comparison matrix: methods by features.
- Benchmark table: models by metrics.
- Ablation table: conditions by results.
- Taxonomy table: categories and representative works.
- Meta-analysis table: cross-paper aggregated evidence.

## Table Rules

- Use `booktabs`.
- Do not use vertical lines.
- Bold the best result in each metric column when appropriate.
- Experimental values should use mean plus standard deviation.
- Captions must state the key finding.
- Performance numbers must come from `results_numbers.tex` macros generated by `collect_paper_results.py`; do not hand-type benchmark values into LaTeX.
- Planned-only cells should display `??` or explicit planned markers, not invented values.

## Figure Rules

Priority:

1. TikZ for architecture and formal diagrams.
2. Matplotlib PDF for data.
3. SVG converted to PDF.
4. High-DPI PNG only when vector output is impractical.

Checklist:

- Vector PDF preferred.
- PNG at least 300 DPI.
- Font size remains readable after scaling.
- Axes are labeled.
- Legends are present.
- Caption is self-contained.
- Data-backed figures must be recorded in `figures/figure_manifest.json`.
- If no real predictions or metric history exist, write `figures/figure_plan.md` instead of drawing speculative result figures.

## Paper Figure Pipeline

Run:

```powershell
python C:\Users\SunYu\.codex\skills\paper-writing\scripts\generate_paper_figures.py <project_dir>
```

The script looks for:

- `experiments/results/*pred*.jsonl` or `*case*.jsonl` with ground-truth and predicted intervals.
- `experiments/results/*history*.jsonl` or `*curve*.jsonl` with metric trajectories.

For VMR papers, prefer:

- method architecture figure;
- predicted-vs-ground-truth moment timelines;
- boundary-error histogram;
- query-length or video-duration robustness curve;
- qualitative success/failure cases.
