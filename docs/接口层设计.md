## 接口层职责

API Gateway作为前端和后端数据之间的唯一桥梁，承担以下职责：

```
 ┌─────────────────────────────────────────────┐
 │              前端 (SPA)                       │
 │   index.html + app.js + styles.css           │
 └──────────────────┬──────────────────────────┘
                    │ HTTP (fetch / XHR)
                    ▼
 ┌─────────────────────────────────────────────┐
 │          API Gateway (Flask)                  │
 │                                               │
 │  ┌──────────┐ ┌──────────┐ ┌──────────────┐ │
 │  │ 参数验证  │ │ CORS处理  │ │ 错误统一包装  │ │
 │  └──────────┘ └──────────┘ └──────────────┘ │
 │  ┌──────────┐ ┌──────────┐ ┌──────────────┐ │
 │  │ 日志记录  │ │ 响应格式化 │ │ 频率限制     │ │
 │  └──────────┘ └──────────┘ └──────────────┘ │
 └──────────────────┬──────────────────────────┘
                    │
                    ▼
 ┌─────────────────────────────────────────────┐
 │            数据层 (JSON文件)                   │
 │   data/idea_graph/*.json                     │
 │   data/idea_graph/paper_cards/*.json         │
 │   data/idea_graph/paper_micro_cards/*.json   │
 └─────────────────────────────────────────────┘
```

**核心职责**：

1. **请求参数验证**：检查必填参数、类型、范围，防止非法输入到达数据层
2. **统一响应格式**：所有响应包装为 `{code, message, data, pagination?}` 格式
3. **统一错误处理**：异常统一捕获，按错误码规范返回结构化错误信息
4. **CORS支持**：允许前端跨域访问（开发环境 `localhost:8765` → `localhost:5000`）
5. **日志记录**：记录每个请求的方法、路径、参数、耗时、状态码
6. **频率限制**：对API调用频率做基本限制，防止过度请求

### 2.3 中间件注册

```python
# app.py
from flask import Flask
from flask_cors import CORS

app = Flask(__name__)
CORS(app, resources={r"/api/*": {"origins": "*"}})

# 请求日志中间件
@app.before_request
def log_request():
    g.start_time = time.time()

@app.after_request
def log_response(response):
    duration = (time.time() - g.start_time) * 1000
    app.logger.info(f"{request.method} {request.path} → {response.status_code} ({duration:.0f}ms)")
    return response
```

## 统一响应格式

### 3.1 成功响应

```python
# middleware/response.py
from flask import jsonify

def success(data=None, message="success", code=200, pagination=None):
    """构建统一成功响应"""
    body = {
        "code": code,
        "message": message,
        "data": data if data is not None else {}
    }
    if pagination:
        body["pagination"] = {
            "page": pagination.get("page", 1),
            "page_size": pagination.get("page_size", 20),
            "total": pagination.get("total", 0),
            "total_pages": pagination.get("total_pages", 1)
        }
    return jsonify(body), code

def make_pagination(page, page_size, total):
    """构建分页信息"""
    return {
        "page": page,
        "page_size": page_size,
        "total": total,
        "total_pages": max(1, (total + page_size - 1) // page_size)
    }
```

### 3.2 使用示例

```python
# routes/papers.py
@ papers_bp.route('', methods=['GET'])
def list_papers():
    page = request.args.get('page', 1, type=int)
    page_size = request.args.get('page_size', 20, type=int)
    year = request.args.get('year', None, type=int)

    # 参数验证
    if page < 1:
        return error(400, "page must be >= 1")
    if page_size < 1 or page_size > 100:
        return error(400, "page_size must be between 1 and 100")

    # 查询数据
    papers, total = paper_service.query_papers(page, page_size, year)

    return success(
        data=papers,
        pagination=make_pagination(page, page_size, total)
    )
```

## 错误处理规范

### 4.1 错误码枚举

```python
# middleware/error_handler.py
class ErrorCode:
    SUCCESS = 200
    BAD_REQUEST = 400         # 参数格式错误
    NOT_FOUND = 404           # 资源不存在
    UNPROCESSABLE = 422       # 参数语义错误
    TOO_MANY_REQUESTS = 429   # 频率限制
    INTERNAL_ERROR = 500      # 服务器内部错误
```

### 4.2 错误响应构建

```python
def error(code, message, error_type=None, detail=None):
    """构建统一错误响应"""
    body = {
        "code": code,
        "message": message,
        "data": None
    }
    if error_type or detail:
        body["error"] = {}
        if error_type:
            body["error"]["type"] = error_type
        if detail:
            body["error"]["detail"] = detail
    return jsonify(body), code
```

### 4.3 全局异常捕获

```python
@app.errorhandler(404)
def handle_not_found(e):
    return error(404, "Endpoint not found", "NOT_FOUND",
                 f"The requested URL {request.path} does not exist.")

@app.errorhandler(500)
def handle_server_error(e):
    app.logger.exception("Unhandled exception")
    return error(500, "Internal server error", "INTERNAL_ERROR",
                 "An unexpected error occurred. Please try again later.")
```

### 4.4 业务错误处理

```python
# services/paper_service.py
class PaperNotFoundError(Exception):
    def __init__(self, paper_id):
        self.paper_id = paper_id
        self.message = f"Paper not found: {paper_id}"

# routes/papers.py
@ papers_bp.route('/<paper_id>', methods=['GET'])
def get_paper(paper_id):
    try:
        paper = paper_service.get_paper_detail(paper_id)
        return success(data=paper)
    except PaperNotFoundError as e:
        return error(404, e.message, "NOT_FOUND",
                     f"No paper with id '{paper_id}' in the library.")
```

### 4.5 错误场景处理表

| 场景 | HTTP码 | error.type | 说明 |
|------|--------|------------|------|
| idea_id 不存在 | 404 | NOT_FOUND | 如 `FI999` 超出范围 |
| paper_id 不存在 | 404 | NOT_FOUND | 论文ID拼写错误 |
| page < 1 | 400 | BAD_REQUEST | 分页参数越界 |
| page_size > 100 | 400 | BAD_REQUEST | 分页大小超限 |
| year 非数字 | 400 | BAD_REQUEST | 类型错误 |
| idea 参数缺失 | 400 | BAD_REQUEST | `/api/graph/root` 缺 `?idea=` |
| 超过频率限制 | 429 | RATE_LIMITED | 同IP 1分钟内>100次请求 |
| JSON文件读取失败 | 500 | INTERNAL_ERROR | 磁盘错误或文件损坏 |
| 未预期异常 | 500 | INTERNAL_ERROR | 全局兜底 |

## 后端实现架构

### 5.1 技术选型

| 组件 | 选择 | 理由 |
|------|------|------|
| Web框架 | Flask 3.x | Python生态最广泛的轻量框架，学习成本低 |
| CORS | flask-cors | 一行配置解决跨域 |
| 数据源 | 本地JSON文件 | 与现有 `data/idea_graph/` 目录无缝对接 |
| 服务运行 | `python app.py` | 与现有 `python -m http.server` 风格一致 |

### 5.2 数据加载器

```python
# data_loader.py — 核心设计
class DataLoader:
    """一次性加载全部JSON到内存，后续查询走内存索引"""

    def __init__(self, data_root: str):
        self.data_root = Path(data_root)
        self.ideas = []               # 60条
        self.micro_problems = {}      # 145个
        self.micro_methods = {}       # 229个
        self.paper_cards = []         # 300条
        self.paper_index = {}         # 全文索引
        self._loaded = False

    def load_all(self):
        """一次性加载全部JSON，构建内存索引"""
        self.ideas = self._load_json('idea_opportunities_finegrained.json')
        self.micro_problems = self._load_json('micro_problem_clusters.json')
        self.micro_methods = self._load_json('micro_method_clusters.json')
        self.paper_cards = self._load_json('paper_micro_cards_index.json')
        self.paper_index = self._load_json('paper_index.json')
        self._build_indices()
        self._loaded = True

    def _build_indices(self):
        """构建查询索引"""
        self.paper_by_id = {p['paper_id']: p for p in self.paper_cards}
        self.idea_by_id = {i['idea_id']: i for i in self.ideas}
        # 构建问题→论文反向索引
        self.papers_by_problem = defaultdict(list)
        for p in self.paper_cards:
            for pu in p.get('problem_units', []):
                self.papers_by_problem[pu['macro_problem_id']].append(p['paper_id'])

    def is_ready(self):
        return self._loaded
```

### 5.4 静态文件服务

Flask后端同时serve前端静态文件，统一端口：

```python
# app.py
from flask import send_from_directory

@app.route('/')
def serve_index():
    return send_from_directory(app.config['STATIC_DIR'], 'index.html')

@app.route('/<path:filename>')
def serve_static(filename):
    return send_from_directory(app.config['STATIC_DIR'], filename)
```

开发时推荐：前端 `8765` 端口 + 后端 `5000` 端口分离运行。
生产时：统一由 Flask 在 `5000` 端口同时 serve 前端静态文件 + API。
