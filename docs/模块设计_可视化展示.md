## 组件1：Idea森林星图

### 1.1 设计目标

以节点式力导向布局展示全部60个Idea候选方向，用户可快速识别高潜力方向、理解Idea之间的关联关系，并点击进入深度探索。

### 1.2 视觉编码

| 节点属性 | 编码方式 | 数据来源 |
|----------|----------|----------|
| 大小 | 半径 = 27 + scoreT × 16，featured项额外 +24 | `idea.score` 潜力分 |
| 亮度 | halo层透明度 = 0.22 + evidence/145 | `idea.evidence` 证据强度 |
| 颜色 | 按目标问题族分类着色（8类色板） | `idea.targetId` → `micro_problem_clusters[].macro_problem_name` |
| 光晕 | 呼吸动画脉冲，非featured节点青色发光，featured节点金色发光 | — |

**颜色映射表（8类问题族）**：

| 问题族 | 颜色 | 色值 |
|--------|------|------|
| Weak Supervision & Annotation | 蓝紫 | `#7c8aff` |
| Sparse Evidence / Long Video | 青绿 | `#3d8cff` |
| Proposal / Ranking Failure | 橙红 | `#ff6b6b` |
| Temporal Context Robustness | 琥珀 | `#ffc857` |
| Compositional Reasoning | 品红 | `#e879f9` |
| Boundary Structure & Precision | 翠绿 | `#42d998` |
| Domain Adaptation | 天蓝 | `#47e6ff` |
| Shortcut Bias / Spurious | 粉橙 | `#fb923c` |

### 1.3 连线

| 连线类型 | 视觉效果 | 语义 |
|----------|----------|------|
| 共享问题 (`shared-problem`) | 实线，width=2.2，opacity=0.34，青色 | 两个Idea共享同一个目标微问题 |
| 共享方法 (`shared-method`) | 虚线(dash 7 7)，width=1.2，opacity=0.20，cyan | 两个Idea共享同一个来源微方法 |

连线生成逻辑：
- 按 `targetId`（问题）和 `methodId`（方法）分组
- 每组取分数前8个Idea，顺序连线
- featured节点(FI001)额外与同组5个节点连线
- 去重后截断至最多180条

### 1.4 交互

| 交互 | 触发 | 行为 |
|------|------|------|
| Hover | 鼠标悬停节点 | 显示浮动卡片：标题、摘要、潜力/证据/新颖/可验四维mini bar |
| Click | 点击节点 | 切换到树根探索视图，URL更新为 `?idea=FI001` |
| 缩放 | 鼠标滚轮 | 缩放范围 0.45x ~ 2.8x |
| 平移 | 拖拽空白区域 | 自由平移画布 |
| 重置 | 点击"重置视图"按钮 | 恢复默认 transform(0,0,1) |
| 高亮关联 | hover节点 | 当前节点高亮，其他节点dim(透明度0.22)，关联连线高亮 |

### 1.5 技术实现

- **渲染**：原生 SVG（viewBox="0 0 1600 900"），无第三方可视化库
- **布局**：放射状分组布局，按问题族分簇，簇内螺旋排列
- **动效**：CSS animation `breathe`（3.4s周期）控制光晕呼吸，`transition` 控制hover过渡
- **拖拽**：Pointer Events API，捕获pointer后计算delta平移

- 布局计算：`app.js:304-387` (`computeForestGraph`)
- 节点渲染：`app.js:441-456` (`renderForestNode`)
- 连线渲染：`app.js:426-439` (`renderForestLinks`)
- 交互绑定：`app.js:489-593` (`bindGraphPanZoom`, `bindForestHover`)

## 组件2：树根探索图谱

### 2.1 设计目标

按层级展示单个Idea的完整推理链：从研究主张→问题缺口→失败根因→迁移方法→论文证据，形成从"为什么值得做"到"用什么证据支持"的可回溯链条。

### 2.2 节点类型

| 节点类型 | 形状 | 颜色 | 大小 | 语义 |
|----------|------|------|------|------|
| **idea** | 大圆(r=62) | 金色 `#ffc857` | size×1.28 | 候选研究主张 |
| **trunk** | 中圆(r=50) | 蓝色 `#3ea2ff` | size×1.1 | 核心思路（一句话主干） |
| **problem** | 中圆(r=47) | 红色 `#ff5d6c` | size×1 | 研究缺口 / 待解决问题 |
| **failure** | 中圆(r=43) | 橙色 `#fb923c` | size×1 | 失败模式 / 根因 |
| **method** | 中圆(r=45) | 绿色 `#42d998` | size×1 | 已有方法 / 可迁移机制 |
| **paper** | 小圆(r=38) | 灰色 `#d8e5f8` | size×1 | 论文证据 |

节点大小 = 基础半径 × size系数，其中size与置信度正相关。

### 2.3 连线类型

| 连线类型 | 样式 | 语义 | 示例 |
|----------|------|------|------|
| `claim` | 实线，opacity 1.0，金色 | Idea→Trunk 核心主张 | "面向长视频稀疏证据的结构化证据链世界模型" → 具体思路 |
| `root` | 实线，opacity 0.84-0.92，蓝色 | Trunk→Problem 直接缺口 | 主干 → 具体研究缺口 |
| `cause` | 实线，opacity 0.80-0.94，红色 | Problem→Failure 根因推导 | 稀疏证据困难 → 显著片段覆盖低频证据 |
| `cross-cause` | 虚线，opacity 0.74-0.78，红色 | 跨问题共享根因 | 两个根因间的交叉影响 |
| `transfer` | 实线，opacity 0.76-0.93，绿色 | Failure→Method 方法迁移 | 根因 → 已有解决机制 |
| `evidence` | 实线，opacity 0.62-0.72，灰色 | 任意节点→Paper 论文支撑 | 方法节点 → 证据论文 |
| `shared-mechanism` | 虚线，opacity 0.58-0.66，灰色 | Method→Method 机制共享 | 两种方法共享结构化推理 |

连线使用垂直曲线(`verticalCurve`)：M起点 C起点中点, 终点中点, 终点

### 2.4 交互

| 交互 | 行为 |
|------|------|
| Click 节点(非paper非idea) | 聚焦该节点，高亮其祖先+后代链，激活"当前分支"过滤 |
| Click paper节点 | 展开论文详情抽屉（右侧slide-out panel） |
| Hover 节点 | 浮动卡片显示：名称、详情、类型·置信度 |
| Hover 连线 | 浮动卡片显示：连接原因描述 |
| 过滤器按钮 | "展开全部" / "只看主路径"(每类top节点) / "高置信度根系"(conf≥78) / "当前分支" |
| 缩放平移 | 同森林视图 |
| 重置 | 恢复默认transform + 展开全部 |
| Esc键 | 关闭论文抽屉；若已关闭则返回森林视图 |

### 2.5 图谱构建逻辑

**Featured Idea (FI001)** 使用硬编码的专家图谱（`buildFeaturedRootGraph`）：
- 手动定义了 18 个节点（1 idea + 1 trunk + 3 problem + 4 failure + 6 method + 7 paper）
- 手动定义了 23 条连线，每条标有语义标签
- 适合展示系统的"旗舰案例"

**通用 Idea** 使用模板化图谱（`buildGenericRootGraph`）：
- 从 `idea_opportunities_finegrained.json` 的字段自动生成 11 个核心节点
- 论文证据自动关联到对应节点

### 2.6 技术实现

- **渲染**：原生 SVG，每个节点为 `<g>` 组（halo圆 + core圆 + label文本 + meta文本 + 证据标记）
- **布局**：固定(x,y)坐标，手动分层（idea y≈172, trunk y≈292, problem y≈425, failure y≈565, method y≈705, paper y≈840）
- **过滤**：通过 BFS 祖先/后代计算实现分支聚焦
- **高亮**：hover时高亮当前节点+祖先链+后代链+直接连线

### 2.7 关键代码位置

- 图谱构建：`app.js:653-818` (`buildRootGraph`, `buildFeaturedRootGraph`, `buildGenericRootGraph`)
- 过滤逻辑：`app.js:853-871` (`filterRootGraph`)
- 节点/连线渲染：`app.js:874-910` (`renderRootNode`, `renderRootEdge`)
- 交互绑定：`app.js:912-985` (`bindRootHover`, `setRootHighlight`, `clearRootHighlight`)

## 组件4：论文详情页

### 4.1 设计目标

从树根探索中的"论文证据"抽屉升级为独立详情页，展示论文基本信息、问题-方法-效果、证据链引用、关联论文推荐。

### 4.2 页面内容结构

```
+----------------------------------------------------------+
|  [← 返回图谱]                              论文详情      |
+----------------------------------------------------------+
|                                                           |
|  # 论文标题                                               |
|  作者1, 作者2, ... | 2024 | EMNLP 2024                    |
|                                                           |
|  +------------------------+  +---------------------------+ |
|  | 摘要                    |  | 论文信息卡片              | |
|  | 完整摘要文本...          |  | 任务范围: VMR            | |
|  |                         |  | 数据集: Charades-STA,    | |
|  |                         |  |          QVHighlights    | |
|  |                         |  | 指标: R@1, mIoU          | |
|  +------------------------+  +---------------------------+ |
|                                                           |
|  +------------------------------------------------------+ |
|  | 问题-方法-效果                                        | |
|  |                                                       | |
|  | 研究问题: [problem_units 列表]                         | |
|  | 提出方法: [method_units 列表]                          | |
|  | 解决方式: [problem_method_links]                       | |
|  +------------------------------------------------------+ |
|                                                           |
|  +------------------------------------------------------+ |
|  | 证据链与来源引用                                       | |
|  |                                                       | |
|  | > "原文引用句1..."  — Introduction, p.3               | |
|  | > "原文引用句2..."  — Method, p.5                     | |
|  +------------------------------------------------------+ |
|                                                           |
|  +------------------------------------------------------+ |
|  | 关联论文推荐                                           | |
|  |                                                       | |
|  | [论文卡片1] [论文卡片2] [论文卡片3] [论文卡片4]        | |
|  | 共享问题/方法/数据集                                   | |
|  +------------------------------------------------------+ |
|                                                           |
+----------------------------------------------------------+
```

### 4.3 功能模块

**4.3.1 基本信息区**
- 标题（完整显示）、作者列表、发表年份、期刊/会议名
- 任务范围标签（VMR / Video Grounding / Adjacent Task）
- 使用的数据集和评估指标

**4.3.2 问题-方法-效果区**
- 从 `paper_micro_cards` 的 `problem_units` 提取研究问题
- 从 `method_units` 提取提出方法
- 从 `problem_method_links` 提取"用什么方法解决什么问题"的对应关系
- 用卡片式布局展示

**4.3.3 证据链区**
- 从 `intro_motivation_chain` 提取三段式证据：
  - `prior_work_limitation`：前人工作局限
  - `core_problem_transition`：核心问题过渡
  - `method_transition`：方法过渡
- 每条证据显示：引用文本 + 来源章节 + 页码

**4.3.4 关联论文推荐**
- 推荐逻辑：共享 `problem_units` 或 `method_units` 中的关键词
- 共享数据集（`datasets` 字段交集）
- 同一年份窗口（±2年）
- 最多推荐4篇，以卡片形式展示（标题+年份+共享原因）

### 4.4 交互

| 交互 | 行为 |
|------|------|
| 点击"返回图谱" | 回到树根探索视图，保留当前Idea |
| 点击关联论文卡片 | 跳转到该论文的详情页 |
| 点击数据集标签 | 高亮该数据集的统计信息 |
| Esc键 | 返回树根探索视图 |

### 4.5 技术实现

- **路由方案**：URL hash `#paper=2024_xxx` 或 query `?paper=2024_xxx`
- **渲染**：纯 HTML/CSS，从 `paper_micro_cards_index.json` + `paper_index.json` 查询
- **关联推荐**：基于共享 `problem_units`/`method_units` 的 Jaccard 相似度计算

### 4.6 新增代码位置

- 渲染逻辑：`app.js` → 新增 `renderPaperPage(paperId)` 函数
- 关联推荐：`app.js` → 新增 `findRelatedPapers(paperId, limit=4)` 函数
- 样式：`styles.css` → 新增 `.paper-page-*` 样式族
- 路由：`app.js` → 修改 `bindGlobalEvents()`，处理 `#paper=` hash

## 组件间交互流程

```
 ┌─────────────────────┐
 │   Idea森林星图       │  60个Idea节点，按问题族分组
 │   (Forest View)      │  hover→卡片 click→进入Root
 └────────┬────────────┘
          │ click Idea节点
          ▼
 ┌─────────────────────┐
 │   树根探索图谱        │  18-25个节点，6种类型，层级布局
 │   (Root View)        │  click paper→详情页
 └────────┬────────────┘          │
          │                       │ click paper节点
          │                       ▼
          │              ┌─────────────────────┐
          │              │   论文详情页          │  独立页面
          │              │   (Paper Page)       │  含关联推荐
          │              └─────────────────────┘
          │
          │ 顶部导航: [森林] [仪表盘]
          ▼
 ┌─────────────────────┐
 │   分析仪表盘          │  4个ECharts图表
 │   (Dashboard)        │  饼图+折线+柱状+雷达
 └─────────────────────┘
```

**导航方式**：
- 森林 → 树根：点击Idea节点
- 树根 → 论文详情：点击paper节点
- 论文详情 → 树根：点击"返回图谱" / Esc
- 任意视图 → 分析仪表盘：顶部导航按钮
- URL参数：`?idea=FI001` / `#paper=2024_xxx` 支持直接链接
